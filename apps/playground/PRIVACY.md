# Datenschutzerklärung – Playground

Stand: 2026

**Playground** ist eine Entwickler-App zum Ausprobieren von Technik-Experimenten. Sie ist nicht im App Store oder bei Google Play veröffentlicht.

## Welche Daten werden erhoben?

**Keine.** Die App

- erhebt keine personenbezogenen Daten,
- fordert keine Berechtigungen an (kein Standort, keine Kamera, keine Kontakte),
- sendet keine Daten an einen Server,
- enthält keine Werbung und kein Tracking.

Alle Experimente – inklusive der eingebetteten Godot-Engine – laufen ausschließlich lokal auf dem Gerät.

## Over-the-Air-Updates

Die App kann über [EAS Update](https://docs.expo.dev/eas-update/introduction/) neue JavaScript-Versionen laden. Dabei wird beim Start eine Anfrage an `u.expo.dev` gestellt; übertragen werden nur technische Angaben (App-Version, Plattform, Update-Kanal), keine personenbezogenen Daten.
